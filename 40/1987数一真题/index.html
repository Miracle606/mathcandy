    第 1 题 ¶

    Example

    与两直线

    \[ \begin{cases} x = 1,\\ y = -1 + t,\\ z = 2 + t \end{cases} \quad \text{及 } \dfrac{x+1}{1}=\dfrac{y+2}{2}=\dfrac{z-1}{1} \]

    都平行，且过原点的平面方程为？

    解：通过两个直线的方向向量的即可得到待求平面的法向量，再结合屏幕过原点即可求解 .

    第 2 题 ¶

    Example

    当 \(x =\) ? 时，函数 \(y = x 2 ^ { x }\) 取得极小值。

    解：高中求导题。

    第 3 题 ¶

    Example

    由曲线 \(y = \ln x\) 与两直线 \(y = (e+1)-x\) 及 \(y = 0\) 所围成的平面图形的面积为 ?

    解：首先联立求解交点，画出草图，不难发现沿直线 \(x=e\) 分为左右两个部分求面积比较容易，左侧直接积分，右侧是一个三角形。

    第 4 题 ¶

    Example

    设 \(L\) 为取正向的圆 \(x ^ { 2 } + y ^ { 2 } = 9 .\)，则曲线积分 \(\displaystyle\oint\limits _ { L } ( 2 x y - 2 y ) \mathrm { d } x + \left( x ^ { 2 } - 4 x \right) \mathrm { d } y\) 的值为？

    解：\(\mathrm{Green}\) 公式模板题，没啥说的。

    第 5 题 ¶

    Example

    已知 \(3\) 维线性空间的一组基为 \(\pmb { \alpha } _ { 1 } = ( 1 , 1 , 0 ) , \pmb { \alpha } _ { 2 } = ( 1 , 0 , 1 ) , \pmb { \alpha } _ { 3 } = ( 0 , 1 , 1 )\)，则向量 \({ \pmb { \alpha } } = ( 2 , 0 , 0 )\) 在上述基底下的坐标为 ?

    解：题意实际上就是用三个已知向量线性表示向量 \({ \pmb { \alpha } } = ( 2 , 0 , 0 )\)，列出线性方程组求解即可。

    第 6 题 ¶

    Example

    求正常数 \(a\) 与 \(b ,\) 使得 \(\displaystyle\operatorname* { l i m } _ { x \to 0 } { \frac { 1 } { b x - \sin x } } \int _ { 0 } ^ { x } { \frac { t ^ { 2 } } { \sqrt { a + t ^ { 2 } } } } \mathrm { d } t = 1\) 成立。

    解：首先根据极限存在分析极限类型，从而得到 \(b=1\)，再根据极限为 \(1\) 结合洛必达即可求出 \(a\) 的值，基础题。

    第 7 题 ¶

    Example

    设函数 \(f , g\) 连续可微，\(u = f ( x , x y ) , v = g ( x + x y )\) , 求 \(\displaystyle\frac { \partial u } { \partial x } \cdot \frac { \partial v } { \partial x } .\)

    解：常规计算题。

    第 9 题 ¶

    Example

    求微分方程 \(y ^ { \prime \prime \prime } + 6 y ^ { \prime \prime } + \left( 9 + a ^ { 2 } \right) y ^ { \prime } = 1\) 的通解，其中常数 \(a > 0\)

    解：基础题，先求齐次通解，再求非齐次特解。

    第 10 题 ¶

    Example

    设常数 \(k > 0\) , 则级数 \(\displaystyle\sum _ { n = 1 } ^ { \infty } ( - 1 ) ^ { n } { \frac { k + n } { n ^ { 2 } } }\) ？

    (A) 发散

    (B) 绝对收敛

    (C) 条件收敛

    (D) 收敛或发散与 \(k\) 的取值有关

    解：先加绝对值判断是否绝对收敛，容易发现可以拆成一个收敛级数 + 一个发散级数，因此是发散的，即不绝对收敛。

    接着判断原级数的敛散性，由于是交错级数，因此考虑使用莱布尼兹判别法，得出收敛。

    综合两方面，原级数条件收敛。

    第 11 题 ¶

    Example

    设 \(I = t \displaystyle\int _ { 0 } ^ { \frac { s } { t } } f ( t x ) \mathrm { d } x ,\) 其中 \(f(x)\) 为连续函数，\(s > 0 , t > 0\) , 则 \(I\) 的值？

    (A) 依赖于 \(s , t\)

    (B) 依赖于 \(s , t , x\)

    (C) 依赖于 \(t , x\), 不依赖于 \(s\)

    (D) 依赖于 \(s\), 不依赖于 \(t\)

    解：换元即可。

    第 12 题 ¶

    Example

    设 \(\displaystyle \lim _ { x \to a } { \frac { f ( x ) - f ( a ) } { ( x - a ) ^ { 2 } } } = - 1\) ，则在点 \(x = a\) 处？

    (A) \(f (x)\) 可导且 \(f ^ { \prime } ( a ) \neq 0\)

    (B) \(f (x)\) 取得极大值

    (C) \(f (x)\) 取得极小值

    (D) \(f(x)\) 的导数不存在

    解：考虑极限的保号性，结合极大值的定义即可知道 B 选项是正确的。

    对于 A、D 两个选项，说的是同一个事情，考虑导数定义即可，注意凑出题干的条件。

    第 13 题 ¶

    Example

    设 \(A\) 为 \(n\) 阶矩阵，且 \(| A | = a \neq 0\) ， \(A ^ { * }\) 是 \(A\) 的伴随矩阵 , 则 \(|A^{*}|=\) ？

    (A) \(a\)

    (B) \(\dfrac { 1 } { a }\)

    (C) \(a ^ { n - 1 }\)

    (D) \(a ^ { n }\)

    解：结合逆矩阵的定义和行列式性质即可：

    \[ \det(kA)=k^{n}\det (A) \]

    第 14 题 ¶

    Example

    求幂级数 \(\displaystyle\sum _ { n = 1 } ^ { \infty } { \frac { 1 } { n 2 ^ { n } } } x ^ { n - 1 }\) 的收敛域，并求其和函数 .

    解：幂级数基础题，收敛域使用比值判别法和根值判别法都可以，我这里使用的是后者；对于和函数的求解，由于可以凑出 \(\mathrm{Taylor}\) 级数形式，因此直接凑就行了，如下两个公式需要熟练掌握：

    \[ \sum_{n=1}^{\infty} \frac{(-1)^{n-1}x^{n}}{n}=\ln(1+x),\quad x\in(-1,1] \]
    \[ \sum_{n=1}^{\infty} \frac{x^{n}}{n}=-\ln(1-x),\quad x\in[-1,1) \]

    第 15 题 ¶

    Example

    计算曲面积分 \(\displaystyle I = \iint_S x(8y + 1)\mathrm{~d}y\mathrm{d}z + 2\left(1 - y^2\right)\mathrm{~d}z\mathrm{d}x - 4yz\mathrm{~d}x\mathrm{d}y\)，其中 \(S\) 是由曲线 \(\begin{cases} z = \sqrt{y - 1},\\ x = 0 \end{cases}\ (1 \leqslant y \leqslant 3)\) 绕 \(y\) 轴旋转一周所成的曲面，它的法向量与 \(y\) 轴正方向的夹角大于 \(\dfrac{\pi}{2}\).

    解：首先先根据解析几何知识求出旋转抛物面方程。然后补面后运用 \(\mathrm{Gauss}\) 公式即可。对于使用 \(\mathrm{Gauss}\) 公式得到的这个三重积分，考虑使用截面法运算量是最小的。

    第 16 题 ¶

    Example

    设函数 \(f(x)\) 在闭区间 \([0,1]\) 上可微，对于 \([0,1]\) 上的每个 \(x\)，函数的值都在区间 \((0,1)\) 内，且 \(f'(x)\neq 1\)，证明：在 \((0,1)\) 内有且仅有一个 \(x\)，使得 \(f(x)=x\).

    解：早年的中值定理证明题还是很简单的，考虑从存在性和唯一性两个方面进行说明即可。

    构造辅助函数结合零点定理即可说明存在性；通过反证法结合 \(\mathrm{Rolle}\) 定理即可说明唯一性。

    第 18 题 ¶

    Example

    假设在一次试验中，事件 \(A\) 发生的概率为 \(p\) ，现进行 \(n\) 次独立试验，则 \(A\) 至少发生一次的概率为 ？，而事件 \(A\) 至多发生一次的概率为 ？.

    解：二项分布，正难则反。

    第 19 题 ¶

    Example

    三个箱子，第一个箱子中有 \(4\) 个黑球 \(1\) 个白球，第二个箱子中有 \(3\) 个黑球 \(3\) 个白球，第三个箱子中有 \(3\) 个黑球 \(5\) 个白球。现随机地取一个箱子，再从这个箱子中取出 \(1\) 个球，这个球为白球的概率等于 ？。已知取出的球是白球，此球属于第二个箱子的概率为 ？.

    解：全概率公式，\(\mathrm{Bayes}\) 公式。

    第 21 题 ¶

    Example

    设随机变量 \(X,Y\) 相互独立，其概率密度函数分别为

    \[ f_X(x)= \begin{cases} 1, & 0 < x < 1,\\ 0, & else, \end{cases} \]
    \[ f_Y(y)= \begin{cases} \mathrm{e}^{-y}, & y>0,\\ 0, & y\leqslant 0, \end{cases} \]

    求随机变量 \(Z=2X+Y\) 的概率密度函数 \(f_Z(z)\)。

    解：概率论期末难度题，考察二维连续型随机变量的函数分布，常用的方法有两种：分布函数法与（卷积）公式法。

    首先先来看分布函数法，此法是通法，只不过对于个别题目计算量可能会很大。画出草图分类讨论即可，过程如下：

    下面介绍公式法：

    我们设 \((X,Y)\) 的概率密度函数为 \(f(x,y)\).

    公式 1

    如果根据 \(Z=g(X,Y)\) 能反解出 \(Y=h(X,Z)\)，则：

    \[ f_{Z}(z)=\int_{-\infty}^{+\infty} \left| \frac{ \partial h(x,z) }{ \partial z } \right|\cdot f(x,h(x,z)) \mathrm{~d} x \]

    公式 2

    如果根据 \(Z=g(X,Y)\) 能反解出 \(X=\varphi(Y,Z)\)，则：

    \[ f_{Z}(z)=\int_{-\infty}^{+\infty} \left| \frac{ \partial \varphi(y,z) }{ \partial z } \right| \cdot f(\varphi(y,z),y) \mathrm{~d} y \]

    特别地，如果 \(Z\) 关于 \(X,Y\) 的表达式是和、差、积，商的形式，分别又能得到更简单的形式，其中和形式推出来的结论被称为“卷积公式”，这里不再展开，掌握上面这两个一般结论即可，结论形式很有规律，看一遍就能记住了，不用刻意背诵。

    公式的证明使用二重积分的 \(\mathrm{Jacobi}\) 换元即可，感兴趣的读者可以自己尝试。

    使用卷积公式求解本题过程如下，本题用这种方法的好处在于可以避免求出分布函数后又求导，极大减少计算量。
