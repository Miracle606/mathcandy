## Where to Start
Miracle的数学小课糖致力于分享趣味、深刻且实用的数学内容。无论你是刚接触高等数学的本科生，希望拓展数理视野的爱好者，备战期末与考研的备考学子，抑或是深耕教学的数学教师，都能在此收获有价值的资料与思维启发。本站甄选各类数学专题、解题技巧与经典习题，带你从多元视角理解、运用数学，感受逻辑推演的独特魅力。

- 在**高数数分**板块，这里没有教科书式的循序铺陈，更像是刷题途中写下的一册随笔旁注：某一个专题，某一类解题巧思，某一道值得多思几步的经典题目。无论是入门必备的**分部积分**，还是深度拓展的 **Beta 函数专题**，精选的内容，期待带给你新的思考角度。

- 在**线代高代**板块，我整理了若干专题，目前涵盖**矩阵的秩**、**矩阵求逆方法大全**等内容。把碎片化的计算知识点串联成体系，带你梳理线性代数的核心概念与实用解题技巧。

- 在**数学科普**板块，我偶尔离开考纲，顺着一个经典问题看看它的来路。数学不只在答题纸上，也藏在漫长而有趣的追问里。希望能带你从不同角度理解数学，感受数学的魅力。

- 在**数一真题**板块，我从1987年起按年份归档了历年的数一真题详细解答。答案之外，也尽量留下每一步为什么这样走，以及还能怎样走。重要经典的题目均配有知识点梳理及技巧总结，希望能帮助你更好地理解和掌握数学知识。
